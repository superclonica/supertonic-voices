## Use a voice

Install one engine package (not both):

```bash
python -m pip install superclonica-cpu        # any CPU: Windows, macOS, Linux; Python 3.10+
python -m pip install superclonica-gpu-cuda   # NVIDIA GPU: Windows or Linux x86-64; Python 3.11+
```

Then speak with a voice file from this repository:

```python
from superclonica import Superclonica

tts = Superclonica()  # GPU if available, otherwise CPU
audio, sample_rate = tts.synthesize(
    "Hello! This is a free Supertonic 3 voice.", voice="voices/ciri/ciri.json", lang="en", seed=7
)
tts.save("hello.wav", audio)
```

or from the command line:

```bash
superclonica --text "Hello! This is a free Supertonic 3 voice." --voice voices/ciri/ciri.json --lang en --output hello.wav
```

The Supertonic 3 base model (about 400 MB) downloads on the first run. The JSON files are plain
Supertonic 3 voice styles, so they also work with the official Supertonic 3 code.
